# Калькулятор рациона питомцев

Онлайн-калькулятор для расчёта суточного рациона собак и кошек.

## Возможности
- Расчёт калорий по весу и возрасту питомца
- Учёт типа животного (собака/кошка)
- Рекомендации по кормлению

## Использование
Откройте `index.html` в браузере или через GitHub Pages.
